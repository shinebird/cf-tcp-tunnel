# 1.1.2：界面更新（基于已验证可用的 1.1.1）

## 页面结构

- 概览：深蓝渐变状态卡、启动/停止、独立上传/下载速率卡、会话数和累计流量、本地入口复制、后台授权状态及入口。
- 配置：Client/Agent 分段选择，服务器/访问服务/提供服务分组，输入框焦点描边，Token 显示隐藏，折叠的高级连接与 TLS 选项。
- 日志：独立诊断页，深色等宽日志区域，复制完整日志，暂停显示刷新，保留 RDP 自检确认。
- 底部固定导航；内容区滚动，宽屏内容最大 680dp；按钮最小 50dp 高，字段有无障碍标签。

## 使用细节

- 首页“运行中”表示服务正在运行，不表示已经连上远程桌面。详细状态和活动会话仍来自原 LiveState。
- 首页入口是“已保存配置”，不冒充当前运行会话配置；运行时仍可保存配置，但须停止/重启才会应用。
- 在配置页编辑不会自动保存或重启。首页启动会沿用原“保存并启动”行为，保存当前草稿并启动。
- 界面旋转时通过 Activity 内存保留草稿、页面和滚动位置；Token 不写入 saved-instance-state。进程被杀后的未保存草稿不保留。
- 显示 Token 后，离开 Activity 会重新隐藏；不影响 Token 的加密保存方式。
- 日志暂停只暂停显示；服务、转发及日志记录照常运行。只有打开日志页时刷新日志文本，不自动抢占用户的滚动位置。

## 更新与验证

更新完整工程后执行原构建命令即可。输出仍为 app/build/outputs/apk/release/app-release.apk，签名方式不变，可在同一签名下覆盖安装。versionCode=6，versionName=1.1.2-native。

本次修改集中在 MainActivity；Gradle 只更新版本号。与用户验证可用的 1.1.1 基线对比，27 个核心/构建文件 SHA-256 一致，包括 C++、JNI、TunnelService、BackgroundPolicy、ConfigStore、LiveState、Manifest、构建脚本。保留原配置键和权限流程；后台服务日志中的 1.1.1 标记表示未改动的服务基线。

Java 编译检查通过（ECJ3.42、Java17，Android35 API stubs；标准 Java 类使用主机 JVM，临时 R 常量），不是完整 APK 构建。现有 10 项原生来源检查和 8 项主题资源检查通过。未在真机/模拟器渲染界面，尚需验证小屏、大字体、输入法、横屏及真实安装效果。

建议验证：已有配置自动加载；Client/Agent 切换；启动停止与后台 RDP/HTTPS；未保存草稿旋转恢复；显示 Token 后切后台重新隐藏；日志复制/暂停；后台设置入口仍可用。
